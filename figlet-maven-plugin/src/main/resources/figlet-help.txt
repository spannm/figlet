GOALS
-----

  figlet:render       (default phase: validate)

    Renders the configured text as ASCII art. Property placeholders
    like ${project.name} are resolved against the Maven model.
    Parameters:
      figlet.content  Content to render, may use the figlet4j markup DSL
                      (<figletFont name="...">...</figletFont>, <lineBreak/>)
                      to mix multiple fonts with plain text (default: ${project.name})
      figlet.font     Built-in font name (default: standard)
      figlet.fontFile Path to external .flf file
      figlet.width    Output width     (default: 72)
      figlet.strict   Fail on unknown chars (default: true)
      figlet.target   Output target: info/debug/stdout/stderr (default: info)
      figlet.skip     Skip this goal   (default: false)

  figlet:list-fonts   (no default phase — run standalone)

    Lists all available built-in FIGfonts alphabetically.
    Parameters:
      figlet.width    Sample rendering width, used only with figlet.sample (default: 72)
      figlet.metadata Show author/date metadata for each font (default: false)
      figlet.sample   Render a short sample for each font    (default: false)
      figlet.sampleText  Sample text (default: current weekday name)
      figlet.skip     Skip this goal   (default: false)

  figlet:help         (no default phase — run standalone)

    Shows this help text and credits.
    Parameters:
      figlet.skip     Skip this goal   (default: false)
